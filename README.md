# AgroMarket - Módulo Catálogo

## Descripción del proyecto

Este repositorio contiene el módulo **Catálogo de productos** de AgroMarket,
la plataforma web de comercialización de productos agrícolas. El módulo
permite visualizar los productos disponibles con su precio referencial y
filtrarlos por categoría (frutas, hortalizas, granos), como primer paso
hacia la interfaz completa de catálogo del sistema.
